asignados a Dayana. El detalle de cada caso está en
`documentacion/casos-prueba/casos-funcionales-F01-F05.md` y en
`documentacion/casos-prueba/Casos_Prueba_Dayana_F01-F05.xlsx`.

> **Estado actual:** los casos manuales están documentados y **pendientes de
> ejecución**. Las capturas listadas abajo son las **esperadas**; deben
> generarse al ejecutar cada caso. No se incluyen imágenes ficticias.

## Cómo nombrar las capturas

Usar exactamente el nombre de la columna "Archivo de evidencia esperado". Al
capturar, guardar el PNG en esta carpeta y actualizar el estado del caso
(`PASS` / `FAIL` / `BLOCKED`) en el Markdown y en el Excel, registrando el
resultado real observado.
